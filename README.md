## Qué he construido

| Proyecto | Qué hace | Tecnología |
|---|---|---|
| **Plataforma de gestión de clubes** · [web](https://gestion-clubes.netlify.app) | SaaS en producción para clubes deportivos: alumnos, cobros por remesa SEPA, importación de Excel y seguridad multi-cliente. | React · TypeScript · Supabase · PostgreSQL · GitHub Actions |
| **Segundo Entrenador** · [beta](https://segundo-entrenador.netlify.app) | App para entrenadores de fútbol: genera entrenos con 157 ejercicios animados a escala y funciona sin conexión. | React Native · Expo · TypeScript · Supabase |
| **Registro de producción con tablets** | Piezas y paradas por puesto, productividad, alertas y trazabilidad en planta. | Python · Flask · SQLite |
| **Panel de producción en tiempo real** | Importa solo los datos de las tablets y los muestra en la pantalla de la nave. | Python · API REST · JavaScript |
| **Documentación de fabricación automática** | Lee planos PDF con OCR, calcula medidas de curvado, genera etiquetas con código de barras e imprime por lotes. | Python · FastAPI · OCR · pypdf |

## Cómo trabajo

- **Primero el proceso, después el código.** Hablo con quien va a usar la herramienta y documento cómo se trabaja de verdad.
- **Desarrollo con IA, dirigido por mí.** Escribo la especificación, reviso lo que se genera y lo valido con pruebas.
- **Pensado para quien lo usa.** Instaladores de un clic, mensajes claros y copias de seguridad automáticas.
